# ✈️ GranTurismo.com: Trabalho de Geografia

Site de uma agência de turismo fictícia, desenvolvido para um trabalho de **Geografia do 2º ano do Ensino Médio**. O roteiro apresentado é uma viagem de 7 dias pela **Irlanda**, passando por **Dublin, Galway e Cork**. O trabalho foi realizado em grupo e toda a parte de pesquisa e relatórios foi feita pelos outros integrantes,porém **o site foi desenvolvido inteiramente por mim**.

## 🌍 Idiomas

O site está disponível em duas versões completas, com o mesmo conteúdo e estrutura:

- 🇧🇷 **Português (Brasil)**: pasta `pt-br/`
- 🇺🇸 **Inglês**: pasta `en/`

Há um botão de troca de idioma na página inicial.

## ✨ Funcionalidades

- **Página inicial** com destinos no Brasil (Fortaleza, Gramado, Ilha de Marajó, Ouro Preto e Rio de Janeiro) e ao redor do mundo (Canadá, Estados Unidos, Inglaterra, Irlanda e Nova Zelândia)
- **Irlanda**: informações gerais sobre o país e as cidades, como idiomas, culinária típica e moeda
- **Pontos Turísticos e Restaurantes** de cada cidade do roteiro
- **Acomodações**: hotéis escolhidos em Dublin, Galway e Cork
- **Transportes**: deslocamentos entre as cidades e dentro de cada uma
- **Preços**: cálculo detalhado do custo total da viagem, com link para um PDF de observações
- **Referências** de pesquisa utilizadas no trabalho
- **Integrantes do grupo** e a divisão das tarefas
- **Páginas dos outros grupos** (Canadá, Estados Unidos, Inglaterra e Nova Zelândia), com slides disponíveis para download
- **Página de erro 404** personalizada

## 🛠️ Tecnologias

- HTML5
- CSS3

Sem frameworks, bibliotecas ou JavaScript: é um site estático.

## ▶️ Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/gscotrim2006/Trabalho-de-Geografia.git
```
2. Entre na pasta do projeto:
```bash
   cd Trabalho-de-Geografia
```
3. Abra o arquivo `pt-br/index.html` (português) ou `en/index.html` (inglês) no navegador.

Não precisa instalar nada.

> ⚠️ O repositório tem cerca de 270 MB por causa das imagens e dos slides, então o clone pode demorar um pouco.
